# 恐龙答题大冒险（RPG 通关游戏）

一只血量 1000 的小恐龙在草地上行走，用答题打败 50 只恐龙，穿过五片领地通关。

## 怎么运行

双击 `index.html` 即可（Chrome / Edge 效果最好，语音需要浏览器支持中文朗读）。

### 单文件版（拷一个文件就能换设备跑）

`恐龙答题大冒险-单文件.html`（约 8.6 MB）把 CSS、11 个 JS（含 `vendor/three.min.js`）和
51 张立绘全部内联，里面没有任何外部引用，拷到平板/手机用浏览器打开即可，
玩法、第一人称 3D 和存档逻辑与多文件版一致。

`dinorpg-tablet.zip`（约 26 MB）是整份工程的多文件版 + 上面那个单文件，解压后两种方式都能跑；
存档写在浏览器本地（`localStorage`），换设备时进度不会跟着文件走。

重新生成（改了代码、立绘或题库之后跑一次）：

```
python tools\build-single.py
python tools\pack-tablet.py
```

立绘会由 420px 的 PNG 压成 300px WebP（14 MB → 1 MB），所以画面尺寸不变、体积只有原来的 1/5。

如果想局域网分享给同学，在本目录执行任意静态服务器，例如
`python -m http.server 8000` 后访问 `http://localhost:8000`。

## 操作

默认是**第一人称 3D**（详见下一节），点 HUD 的「🎥 视角」可以切回原来的俯视 2D 版。

| 按键 | 作用（第一人称） |
| --- | --- |
| 左下摇杆 / ↑ ↓ 或 W S | 相对镜头前后走 |
| ← → | 转身（左右看用**手指拖动画面**或鼠标拖动） |
| Q E | 横移（平移脚步） |
| 1 / 2 / 3 / 4 | 战斗中选 A / B / C / D |
| Enter 或 空格 | 迎战 / 下一题 / 领取奖励 |
| Z | 朗读当前题目（含篇章） |
| Esc | 关闭设置、错题库、玩法面板 |

俯视 2D 版仍是 ↑ ↓ ← → / W A S D 四向走路，手机用左下角方向键。

## 第一人称 3D（js/fp.js + vendor/three.min.js）

打开就是第一人称：整张地图按 **1 像素 = 0.06 米** 等比搬进 3D（约 337 × 156 米），
眼睛高 1.62 米、竖直视野 74°，走路速度约 5.3 米/秒。

- **地形、天空、植被全是代码现场画的**，不额外依赖任何图片：草地/草丛/野花/树/云/名牌
  都用 canvas 画完再上传成贴图；六片领地各有自己的雾色、雾距、天空渐变和地面罩色，
  走过去整片天色就变了。
- **50 只恐龙是 billboard**（永远正对着你），按强度长到 3～8 米高，头顶一块写着
  「#N 中文名 · 强度 · 血量 · 答对几题」的牌子；踩进 80 像素（约 4.8 米）内就开战。
- **走路有起伏和摆头**，静止时也在轻微呼吸，第一人称没有这点动感就会「飘」。
- **战斗镜头自动接管**：`FP.lockFoe()` 把镜头拉到恐龙身前 `max(8, 身高×1.45+5.5)` 米处，
  视线刻意压低 23°，让恐龙整只落在屏幕**上半部分**——下半屏留给题卡（战斗面板在第一人称下
  变成底部浮层，上半屏仍然可以拖动转头）。打完点「击败它」，镜头会滑回主角脚下。
- **特效不用重写**：`fp.js` 每帧把恐龙头部投影到屏幕坐标，写进两个隐形锚点
  `#aFoe` / `#aMe` 的尺寸和位置；`game.js` 的 `foeNode()` / `meNode()` 在第一人称下把
  `FX.strike()`、飘字、粒子都改打到锚点上，所以爪痕、爆裂、金色「−200」照样落在那只恐龙身上。
  另外 `FP.punch()`（镜头前顶 + FOV 收缩）、`FP.hitFoe()`（立绘白闪后仰）、
  `FP.shakeIt()`（镜头抖动）会叠加上去。
- **读档时已经击败过的恐龙**直接消失（`FP.killFoe(e, true)`），不再重演一遍倒下动画。
- 3D 层完全失败也不会白屏：`FP.init()` 里 WebGL 建不起来（老设备、禁用硬件加速）就
  把 `FP.on` 置回 false，`body.fp` 类不加，直接退回原来的俯视版，玩法一模一样。
- 视角偏好记在 `localStorage` 的 `dinorpg.view.v1`（`"3d"` / `"2d"`），切换会刷新页面重建世界。
- 地图坐标仍归 `game.js` 管（`player.x/y` 是像素），`fp.js` 只做 px→米 的换算和镜头，
  所以战斗、题库、存档这些逻辑一行没动。

## 规则

- 主角初始血量 **1000**。
- 走近恐龙即碰面：先来一段「VS」对决开场，它再用低沉男声说一句挑衅台词（**字幕 + 语音**），然后进入车轮战出题。
- **答对一题：敌人 −200 血；答错一题：自己 −200 血。**
- 一题默认 **30 秒**，可在「⚙ 设置」里改成 10 / 15 / 20 / 30 / 45 / 60 / 90 / 120 秒或**不限时**（记在 `localStorage`，键 `dinorpg.qtime.v1`）；超时不扣血，直接换一道题；也可以主动点「换一题」（会计入跳过次数）。
- 敌人血量从 **100 递增到 1000**，共 50 只、10 个强度层级（每 5 只升一级）。
- **随意挑战**：地图上可以想走就走，走近任意一只没被打败的恐龙就开战，不必按 1→50 的顺序。
- 每只恐龙头顶的牌子上写着「强度 N · 血量 · 答对几题」，头下还有一条按强度着色（绿/黄/红）的血条，方便先研判再下手；离得最近的那只会自动显示在右上角雷达里。
- 每击败一只：**血量上限 +50，并当场加满血**。
- **进化**：打败谁就变成谁——主角当场换成那只恐龙的样子，一路保留到通关，HUD 的「形态」会写着现在的名字；存档里记着 `form`，换设备继续进度时形态也在。
- 血量归零：可以满血复活重打当前这一场，**进度不会丢**。
- 击败全部 50 只即通关，结算页显示答对/答错/正确率/时长等数据。
- 地图上另有 10 株发光草药，采一株 **+100 血**（一次性）。

## 对决动画与配音

战斗面板顶部是**对峙双方**：左边主角、右边敌人。
50 张恐龙立绘**全都画成朝左**，只有初始主角 `hero.png` 朝右，所以「谁该镜像」是分开判的：
敌人本来就朝左、和主角脸对脸，容器不用翻；主角一旦进化成恐龙立绘就朝左了，得把整组容器镜像（`.fx-mirror`）才朝右。
`js/fx.js` 的 `mirrored()` 会认这个容器类，扑击/受击的位移方向自动跟着反过来，所以特效打的方向不会错。
第一人称下这两个立绘换成 3D 场景里那只真的恐龙，面板变成底部浮层，特效改打在投影锚点上。

- **形态化身**：第一人称里低头能看见自己变成了什么——一个半透明的当前形态立绘**站**在主角身前偏右，背对着你、也就是面朝前进方向。这里的关键是素材视角而不是旋转角度：50 张恐龙立绘和 `hero.png` 全是侧视图，侧视图贴在竖直平面上绕竖轴怎么转，画面上的头都还在身体左端，看着仍是侧身（试过 `Sprite` 正对镜头=横着头，也试过 `PlaneGeometry` 转到平行前进方向=侧对镜头糊成薄片，两头都不对）。所以每种形态另外配一张**背面立绘**（`assets/dinos/dino-NN-back.png`、`hero-back.png`，用 image-to-image 以对应侧视原图为参考生成同风格的「从背后走开」视角，再走 `tools/clean-dinos.ps1` 抠掉白底、缩到 420×420），`FP.setForm()` 用和敌人同一种 `Sprite`（`center.set(0.5, 0)` 锚在脚底，永远直立），因为第一人称里你永远站在化身身后，背面图天生就是朝前走。背面图缺失时自动退回侧视图（`img.onerror` 兜底），低头至少还能看见自己变成了什么，不会是一片空地。大小随强度递增，进战斗镜头接管时隐藏。横向偏移按 `0.16 × 画面宽高比` 算（`js/fp.js` 里那段注释有推导）：固定米数的偏移在宽屏只压到屏幕 64%、竖屏却顶到 84% 的右下角，改成跟随宽高比后所有设备都稳定落在画面中部偏下（约 55% 宽、脚在 67% 高）。俯视版和战斗面板照旧用侧视图和 `fx-mirror` 翻面，不受影响。

- **恐龙会自己溜达**：地图上的恐龙不是站在出生点当雕塑。`js/fp.js` 的 `stepWander()` 给每只维护一个「走到随机点 → 站着歇 2.5~7.5 秒 → 再换一个点」的循环，速度 0.3~0.65 米/秒（只有玩家脚程的十分之一），起步和停步都缓入缓出。漫游半径被压在「和最近邻居站定时还剩多少空隙」的一半以内，否则强度 10 那种 8 米宽的立绘会走到同伴身上；正在对峙的那只直接冻结，战斗镜头才不会跟着飘。立绘天生朝左，所以往屏幕右边挪时整张图用 `map.repeat.x = -1` 水平翻面（贴图开 `wrapS = RepeatWrapping`，实测屏幕上的明暗两半确实互换，不是翻出空白帧），看着才不是倒着太空步；开战那一刻翻回原图，正对玩家。因为它真的在走，`game.js` 的距离、罗盘指向和「走近开战」判定都改问 `FP.foePos(e)`（返回当前所在的那一格地图像素），看见恐龙站在哪儿，走过去就打得到。俯视 2D 版不参与，仍然是站定的。
- **VS 开场**：走近恐龙即触发，双方从屏幕两侧冲进画面、中间撞出冲击波 + 白闪 + 屏幕震动，撞完才开口放狠话。
- **答对**：主角扑向敌人 → 爪痕 + 粒子爆裂 + 金色「−200」飘字 + 敌人白闪退避；连对 2 题以上显示「连击 ×N」；打掉最后一滴血额外触发「终结一击！」大字 + 全屏亮闪。
- **答错**：敌人反扑 → 主角受击、红色飘字 + 红闪 + 面板震动；血量低于 25% 时屏幕边缘持续红色暗角。
- **击败**：敌人旋转倒下淡出 + 爆裂 + 彩带，然后才收起战斗面板；通关再放两波彩带。
- 题目与选项按 70ms 间隔逐个弹入，读题不会「整屏砸下来」。

配音走浏览器 `speechSynthesis`，`js/audio.js` 里按关键词打分挑音色：

- 优先**本地中文男声**（Windows 自带的康康），其次才是别的中文音色；Edge/Chrome 那些「Online / Natural / Neural」在线音色音质好，但**断网或被网络策略拦掉时会一声不吭**，所以打分里给本地音色 +45、在线 / Natural 明确扣分，保证「先能出声」。
- 挑到男声后整体再乘 0.88 的音高、语速降到 0.94，听起来更沉；**明确是女声**时乘 0.62 把它压浑厚；**听不出性别的音色（平板上的中文引擎很常见）只乘 0.8**——压到 0.6 会让安卓 TTS 糊成一团，宁可糙一点也要能听懂（音高下限锁 0.35，再低 Windows 的语音引擎会吐不出声）。
- 敌人的音色音高按强度递减（越强的恐龙吼得越低），台词下面还垫了一层 Web Audio 现场合成的**恐龙低吼**（噪声 + 双失谐锯齿 + 颤音，基频随强度下降）。
- 音色表是异步加载的，`watchVoices()` 会在 `voiceschanged` 后清缓存重挑，避免第一次开口用了默认女声。
- **平板的坑**：安卓/鸿蒙的普通话经常把 `lang` 报成 `cmn-Hans-CN`、`yue-Hant-HK` 而不是 `zh-CN`，只认 `zh` 开头就会误判成「没有中文音色」；另外 `getVoices()` 首帧多半是空表，要等引擎自己挂上来。所以 `isZhVoice()` 同时看 `lang` 和音色名，空表**不写缓存**，并用 `waitZh()` 最多轮询 3 秒再下结论。
- **发声看门狗**：`speak()` 后 1.8 秒内没等到 `start` 事件就自动换下一个候选音色重试，最多 4 个；全都不出声就弹提示，提示按 `navigator.userAgent` 分成**安卓 / iPad / Windows 各自的设置路径**（`SFX.zhHint()`）。另外队列空着时不再 `cancel()`——Chrome 里 `cancel` 紧接 `speak` 有概率把这句话吞掉。
- 点 HUD 的「🎙 语音」会先等音色表（最多 2.6 秒）再念「语音已开启，我是你的旁白」，并把当前音色名字显示在提示条里，方便一眼看出是没声音还是没开。

### 换设备后听不到念书（平板/手机）

游戏里三处会告诉你到底是哪种情况：**开始冒险时的提示条**、**「⚙ 设置」里那行「这台设备……」**、**「▶ 试听」后面的发声事件**。

- 提示「没报出中文音色」＝系统里没装中文语音包，按提示条里对应设备的路子装；装完回游戏点「🔄 重新扫描音色」。
- 安卓：设置 → 系统管理 / 更多设置 → 语言与输入法 → **文字转语音(TTS)** → 首选引擎选支持中文的，并在「已安装的语言 / 语音数据」里下载 中文(中国)；机器上一个 TTS 引擎都没有时，先装 Google 文字转语音、讯飞或厂商自带引擎。
- iPad/iPhone：设置 → 辅助功能 → 朗读内容 → 语音 → 中文(中国大陆)，下载 Tingting 之类的声音。
- Windows：设置 → 时间和语言 → 语音 → 添加「中文(中国)」并勾选语音合成。
- **用错打开方式也会没声音**：在文件管理器、微信或浏览器「预览」里打开 HTML，常常接不到系统语音（Web Audio 的音效还在，就是没人念书）。请改用 **Chrome / Edge / Safari 直接打开这个文件**。
- 平板上还要确认**媒体音量**没关，只开铃声不影响台词。

HUD 上的「⚙ 设置」面板里可以自己调两件事：

- **每题倒计时**：10 / 15 / 20 / 30 / 45 / 60 / 90 / 120 秒或「不限时」，选完立刻生效（战斗中的话当前这题重新起算），存在 `localStorage` 的 `dinorpg.qtime.v1`。
- **朗读音色**：下拉列出本机全部音色并标好「本地 / 在线」，默认「自动 · 优先本地中文男声」，也可以指定某个音色或退回「系统默认音色」；旁边有「▶ 试听」和音高 / 语速滑杆。试听后面板会把浏览器实际回报的事件（`start / boundary / end / error` + 耗时）打出来——**听得到音效却听不到念书时，看这一行就知道是音色哑了还是系统缺语音包**。音色与滑杆选择存在 `dinorpg.voice.v1`。

HUD 上的「✨ 特效」按钮控制全部对决动画，选择记在 `localStorage`（键 `dinorpg.fx.v1`）。
系统开了「减弱动效」时默认关特效，但玩家手动打开后照样播放。

## 走路脚步声（js/walk-sfx.js）

这个文件由局域网另一台机器（<局域网另一台机器>）实现，本机只负责在 `js/game.js` 里接线，两边不碰同一个文件，避免互相覆盖。

- 接口只有五个方法：`start(terrain)` / `stop()` / `terrain(name)` / `speed(0..1)` / `enabled(on)`。
- `step()` 每帧调 `walkTick()`：停下的那一刻就把 `stop()` 掉，所以不会有「幽灵脚步」；`speed01` 用**实际走速**算，摇杆推一半脚步也慢一半，步频跟着人走而不是跟着配置走。
- 地形名来自 `regionOfX(player.x).theme`，即六大区域各一套合成配方（`plains / valley / volcano / ice / wasteland / island`）。
- 音频**全部现场合成**，不引入任何音频文件；`AudioContext` 复用 `SFX.ctx()`，这样平板上「首次手势解锁」只需要点一次开始按钮。HUD 的「🔊 音效」开关同时管它。
- 常速实测 **2.2 步/秒**，左右脚在音高、声像、力度上都拉开（否则像缝纫机）；单步峰值钉在 **0.08** 以下（`tanh` 软削波兜住同相叠加），保证脚步不会盖过台词。
- 老 WebView 缺 `Math.tanh` 会在建总线时抛错，所以 `walkTick()` 外面套了一层 try：**炸一次就永久停用脚步声**，不让它每帧拖垮主循环。

物理（真题 18 + 补位 16）、化学（15 + 20）、语文（6 + 20）、生物（0 + 16）、地理（0 + 14）带补位题。
浙江的中考理科卷是「科学」综合卷、文科是「社会·法治」综合卷，题目大量依赖图片（受力图、电路图、地图），
且不少语文题要读文段才能作答，所以能被游戏直接用的纯文字真题天然偏少——这类题会被过滤掉而不是硬塞。

- 抽题范围 = 浙江真题 + 兜底题。判定规则写在 `js/questions.js`：某科目真题 ≥ 20 道时只出真题，不足 20 道才把自建/补位题混进池子。
- 战斗出题时先随机选一个**已勾选的科目**，再按敌人强度取对应难度（1–5）的题目；该难度无题则按 ±1、±2… 逐级放宽。
- 每题标注难度 1–5，敌人强度 1–2 级出 1 难度题，3–4 级出 2 难度题，以此类推；同一场战斗内不重复。
- 浙江真题的难度按题目在整卷中的位置估算（越靠后越难），计算题、实验探究题再上调一档。

### 真题里的插图与表格

`docx2txt.ps1` 把 Word 表格摊平成纯文本后，行列边界就丢了，所以插表和「如下表所示」的题需要单独回源还原：

- `extract-images.py` 按 `[图]` 出现位置抽取 `word/media/*`，写出 `images-index.json`；`extract-tables.py` 扫 `word/document.xml` 的 `<w:tbl>` 还原行列网格，按同一套摊平规则在 `_txt` 里定位，写出 `tables-index.json`（偏移 + 行数）。
- `parse.mjs` 拿到索引后把表格区间**原地抹成空格**并插入 `[[TBL:n]]` 占位——长度、换行、`[图]` 字符位置都不动，否则插图索引会错位；已答题区间（`参考答案` 之后）的表格不抹，避免找不到答案解析的分界。
- `build-game-bank.mjs` 把网格压成 `tb` 字段（单格压成一行、最多 24 行 × 14 列），`js/questions.js` 的 `renderRich` 用 `textContent` 拼出真正的 `<table class="qtbl">`，题干 / 选项 / 解析三处都会渲染，不拼 `innerHTML`。
- 图片版（OCR）卷子没有 `.docx` 可回源，这类题的表格只能是摊平文本，抽题时会被丢掉而不是半显示。
- 抽题时按 `如表 / 见表 / 下表 / 表格 / 表中 / 读表 / 统计表 / 统计图 / 扇形图 / 条形图 / 折线图` 检查题干：题干引用了表格却既没拿到 `tb` 网格也没拿到插图，直接判为「无头题」剔除（`dropped.noTblData`）；同理「材料一/材料二/展板」这类依赖原卷材料的题也一并剔除。本轮因此少掉 3 题（430 → 427），换来的是孩子不会再遇到「根据表中数据」却看不到表的题。

### 自选科目

HUD 上的「📚 科目」按钮（开局界面里也有同名按钮）会打开科目面板：

- 每个科目显示「共 N 题 · 浙江真题 x · 补位 y」，勾选/取消即可决定哪些科目会被抽到。
- 底部「只选浙江真题科目 / 全选 / 全不选」可快速调整；选择结果存在 `localStorage`（键 `dinorpg.subjects.v1`），下次打开仍然生效。
- 战斗中打开面板会暂停出题计时，关掉后继续。
- 一道题都没勾选时自动退回「全部科目」，避免打不了仗。
- 战斗界面顶部与错题库都会标明出处，例如 `第 4 题 · 历史（难度 3） · 2020·浙江省嘉兴市、舟山市中考 · 浙江真题`，兜底题则标 `补位题`。

### 真题是从哪来的

`js/questions-zk.js` 是**生成物**，不是手写题库：本机维护着一个近 4 年浙江省中考卷的归档
（扫描卷走 OCR、Word 卷直接抽取），再由一条「摊平文本 → 定位插图与表格 → 拆题 → 按地区过滤 → 拼成
`window.QUESTIONS_ZK`」的管线产出，每条记录都带年份、地区与解析。那条管线和它读的试卷不在本仓库里
（里面是别人的试卷扫描件和孩子自己的错题本），所以这里只发布生成结果。

想自己扩题库，照 `js/questions-zk.js` 记录里的字段（`s/l/stem/o/a/x/y/r/t/g/tb`）写数据就行，
游戏侧「不足 20 道才用补位题兜底」的规则不用改；`tools/build-single.py` 会连带把新题库打进单文件版。

## 错题库

- 答错的题自动进入错题库（存在浏览器 `localStorage`）。
- 错题库中的题**不会在战斗中重复出现**，直到你补回来。
- 在错题库面板点「练这一题」做练习：答对即移出错题库；答错继续留着。
- 也可以直接点「已掌握，移除」。

## 进度保存

进度、血量上限、当前血量、已采草药、答题统计、**当前形态**都存在浏览器本地（`localStorage`），
关掉网页再打开可以点「继续上次进度」，变过身的样子也会一并恢复。HUD 上的「重开」会清空进度和错题库。

## 说明与取舍

- 按「答对一题 −200 血」的规则，打完 50 只共需答对约 150 题，而初始血量只允许答错约 5 次，
  因此采用「车轮战 + 死亡后可满血重打当前一场、进度不丢」的设计，保证小学生、初中生也能真正通关。
- 语音使用系统自带的中文朗读（Windows 上是 Microsoft Huihui / Kangkang / Yaoyao）。
  若设备没有中文语音，台词仍会以字幕显示，并在开局时提示一次。
